# موقع رفع الأفلام

موقع لرفع ومشاهدة الأفلام مع لوحة إدارة.

## الصفحات

- `/` - الصفحة الرئيسية لعرض الأفلام
- `/admin/login` - صفحة تسجيل دخول الإدمن
- `/admin/dashboard` - لوحة تحكم الإدمن (إضافة/تعديل/حذف الأفلام)

## بيانات الدخول الإدارية

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

## النشر على Vercel

1. ارفع المشروع على GitHub
2. اذهب إلى [vercel.com](https://vercel.com) وسجل دخول
3. اضغط على "New Project"
4. اختر المستودع الخاص بك
5. أضف المتغيرات البيئية:
   - `ADMIN_USERNAME`
   - `ADMIN_PASSWORD`
6. اضغط على "Deploy"

## الميزات

- عرض الأفلام مع البوستر والوصف والتقييم
- إضافة أفلام جديدة مع صورة من الجهاز أو رابط
- تعديل وحذف الأفلام
- لوحة إدارة محمية بكلمة مرور
- تخزين البيانات في SQLite
